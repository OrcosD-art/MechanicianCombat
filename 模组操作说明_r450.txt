MechanicianCombat 模组操作说明
版本：r450-2026-10-28

一、环境与前置

Minecraft：1.21.1
Java：21
Fabric Loader：最低 0.16.0，当前测试版本 0.18.2
Fabric API：当前测试版本 0.116.17+1.21.1
GeckoLib：4.8.2
Player Animator：2.0.4+1.21.1
Accessories：1.1.0-beta.54+1.21.1
owo-lib：0.13.0-alpha.15+1.21

推荐安装：
Combat Roll 2.0.6+1.21.1
Shoulder Surfing Reloaded 4.21.0

可选兼容：
Cloth Config 15.0.140
Forge Config API Port 21.1.6
Armor of the Ages 1.5.11

本分发包只包含 MechanicianCombat 本体与文档，不包含 Fabric Loader、Fabric API 或其他前置。请自行安装与 Minecraft 1.21.1、Fabric 对应的版本。

安装 Combat Roll 时，物理翻滚由 Combat Roll 执行；未安装时使用模组内置闪避。安装 Shoulder Surfing 时由其接管越肩视角；未安装时使用模组内置处理。

二、安装方法

1. 安装 Minecraft 1.21.1 对应的 Fabric Loader。
2. 将 Fabric API、GeckoLib、Player Animator、Accessories 和 owo-lib 放入 mods 文件夹。
3. 将 MechanicianCombat-1.0.0.jar 放入同一个 mods 文件夹。
4. 多人游戏中，客户端与服务端必须安装同一版本的 MechanicianCombat。

三、默认按键

右键：瞄准；专注状态下用于调整准星。
左键：射击；专注状态可按住连续射击。
Z：进入或退出专注（架枪）状态。
F：装填当前枪械。
K：打开独立弹药环。
X：使用当前战斗背包零件功能。
Alt：闪避、翻滚或滑铲；安装 Combat Roll 后以 Combat Roll 绑定为准。
鼠标滚轮：手持本模组枪械时切换当前弹仓的弹药种类。

所有按键都可以在“选项 -> 控制”的“机械师”分类中修改。

四、射击与弹药

腰射弹匣容量为 6 发，专注弹匣容量为 10 发。
进入专注状态会立即装填当前选择的弹药。
专注状态前 3 发使用固定的初始射击动画，后续按剩余弹量切换动画。
专注状态打空第 10 发后进入过热，过热期间无法射击和装填。
退出专注和过热状态会给予缓慢效果，动画结束后解除。

当前弹药：
熔铁弩矢：可穿透，横向判定半径 2 格；专注射击间隔加倍。
爆破弹：命中后产生范围伤害与击退。
切割风弹：直击造成三段递减伤害，并产生范围伤害。
幽匿弹：无视护甲，产生音爆范围伤害与击退。
玫瑰石英弹：在飞行后减速，并追踪可见或被背包技能高亮的目标。
霰弹：向锥形区域发射多枚弹丸，距离越远速度越低。

五、专注与快速专注

普通右键瞄准需要完整的 Focus_ready 动作。
滑铲中按 Z 或按右键会进入滑铲快速专注，使用 sliding_fast_ready。
滑铲快速专注开始后的 7 tick 会保留轻微前向惯性，随后立即停止。
翻滚达到 0.38 秒后按 Z，或提前预输入 Z，会进入翻滚快速专注。
准备阶段不能翻滚；完全进入专注射击状态后可以翻滚退出。

六、闪避、翻滚与滑铲

第一次闪避通常为翻滚，翻滚后加速窗口内再次输入闪避键会进入滑铲。
翻滚与滑铲交替进行，完成一轮后会有短暂输入冷却。
滑铲位移由服务端控制，不会因持续按前进键而无限增加。
滑铲结束会延长移动速度加成。
进入滑铲快速专注不会保留完整的 50% 速度加成。

七、弹药环

手持本模组枪械时按 K 打开独立弹药环。
每把枪拥有独立弹仓状态，切换枪械后保留最后选择的弹药位置。
滚轮向上和向下分别对应弹药环的两个旋转方向。
切换动画完成后播报当前弹药名称；弹仓为空时显示“空”。

八、战斗背包

战斗背包装备在 Accessories 的背部槽位。
背包核心和便携发射器需要在背包改装台中安装。
未安装核心时，背包的其他零件不生效。
未安装便携发射器时，背包没有高亮标记和发射功能。
便携发射器会占用副手作为发射物存储槽，可存放烟花火箭、药水箭、风弹和三叉戟。
按 X 根据当前安装的发射器零件执行对应功能。

九、铸造傀儡

铸造傀儡通过专属召唤物或召唤天线生成。
生成时播放落地动画，动画结束前不会受伤。
铸造傀儡会跟随召唤者并攻击敌对生物。
ATK1、ATK2、ATK3 使用不同的攻击范围和冷却。
召唤天线完成标记后会从炮口位置发射尖啸特效并召唤傀儡。

十、已知说明

首次载入自定义实体时，日志可能出现 No data fixer registered，不影响运行。
Player Animator、GeckoLib、Accessories 或 owo-lib 版本不匹配时，游戏会在启动阶段拒绝载入。
本模组运行日志不属于分发包内容，反馈问题时请单独提供 latest.log。
