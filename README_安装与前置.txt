安装：
1. 使用 Minecraft 1.21.1 和 Java 21。
2. 安装 Fabric Loader 0.16.0 或更高版本。
3. 安装 Fabric API、GeckoLib、Player Animator、Accessories 和 owo-lib。
4. 将 mods 文件夹中的 MechanicianCombat JAR 放入游戏的 mods 文件夹。
5. 多人游戏中，服务端和所有客户端必须安装同一版本。

推荐版本：
Fabric Loader 0.18.2
Fabric API 0.116.17+1.21.1
GeckoLib 4.8.2
Player Animator 2.0.4+1.21.1
Accessories 1.1.0-beta.54+1.21.1
owo-lib 0.13.0-alpha.15+1.21

推荐可选：
Combat Roll 2.0.6+1.21.1
Shoulder Surfing Reloaded 4.21.0

本包不包含 Fabric Loader、Fabric API 或其他前置模组。
