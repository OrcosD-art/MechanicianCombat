安装：
1. 使用 Minecraft 1.21.1、Java 21 和 Fabric Loader。
2. 安装 Fabric API。
3. 安装 GeckoLib、Player Animator、Accessories 和 owo-lib。
4. 将 mods 文件夹中的 MechanicianCombat-r774.jar 放入游戏 mods 文件夹。
5. 多人游戏中，客户端与服务端必须安装相同版本。

测试版本：
- Fabric Loader 0.18.2
- Fabric API 0.116.17+1.21.1
- GeckoLib 4.8.2
- Player Animator 2.0.4+1.21.1
- Accessories 1.1.0-beta.54+1.21.1
- owo-lib 0.13.0-alpha.15+1.21
