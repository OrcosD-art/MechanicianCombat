MechanicianCombat r611 分发包

安装：
1. 使用 Minecraft 1.21.1 和 Java 21。
2. 安装 Fabric Loader、Fabric API 与上述依赖。
3. 将 mods/MechanicianCombat-1.0.0.jar 放入游戏的 mods 文件夹。
4. 多人游戏中客户端与服务端必须使用相同版本。

必需内容前置：
- GeckoLib 4.8.2
- Player Animator 2.0.4+1.21.1
- Accessories 1.1.0-beta.54+1.21.1
- owo-lib 0.13.0-alpha.15+1.21

推荐兼容前置：
- Combat Roll 2.0.6+1.21.1
- Shoulder Surfing Reloaded 4.21.0

推荐 Fabric API：0.116.17+1.21.1
推荐 Fabric Loader：0.18.2

本分发包不包含 Fabric Loader、Fabric API 或其他第三方前置 JAR。
本次没有修改第三方前置模组的内容。
