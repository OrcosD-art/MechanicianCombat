MechanicianCombat r508 安装与前置

一、环境

1. Minecraft 1.21.1
2. Java 21
3. Fabric Loader 0.18.2 推荐

二、必需前置

请在启动游戏前自行安装以下 Fabric 模组：

1. Fabric API
   推荐：0.116.17+1.21.1

2. GeckoLib
   推荐：4.8.2

3. Player Animator
   推荐：2.0.4+1.21.1

4. Accessories
   推荐：1.1.0-beta.54+1.21.1

Accessories 所需的传递依赖同样需要按该模组要求安装。

三、推荐模组

1. Better Combat 2.4.0+1.21.1
2. Combat Roll 2.0.6+1.21.1
3. Shoulder Surfing Reloaded 4.21.0

Combat Roll 缺失时，本模组会启用内置 Alt 闪避逻辑。
Shoulder Surfing 缺失时，本模组使用内置越肩视角后备逻辑。
Better Combat 缺失时，本模组自身的近战状态机仍可独立运行。

四、安装

1. 将 MechanicianCombat-1.0.0.jar 放入对应版本的 mods 文件夹。
2. 将全部必需前置放入同一 mods 文件夹。
3. 启动 Minecraft 1.21.1 Fabric。
4. 进入游戏后，日志中应显示构建版本 r508-2026-10-30。

五、多人游戏

服务端和所有客户端必须安装同一个 MechanicianCombat JAR。
本模组会同步枪械状态、近战命中反馈、音效和粒子事件。

六、分发包说明

本分发包仅包含本模组和说明文档，不包含 Minecraft、Fabric Loader、Fabric API 或其他第三方前置。
本次没有修改任何第三方前置模组的内容，因此不附带第三方前置 JAR。
