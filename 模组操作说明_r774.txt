MechanicianCombat r774 操作说明
Minecraft：1.21.1
Java：21
模组内部 ID：mechaniciancombat

一、安装与前置

1. 安装 Fabric Loader 与 Fabric API。
   本版本测试使用的 Fabric API 版本：0.116.17+1.21.1。
2. 必需内容前置：
   - GeckoLib 4.8.2
   - Player Animator 2.0.4+1.21.1
   - Accessories 1.1.0-beta.54+1.21.1
   - owo-lib 0.13.0-alpha.15+1.21
3. 推荐测试环境：
   - Fabric Loader 0.18.2
   - Combat Roll 2.0.6+1.21.1
   - Shoulder Surfing Reloaded 4.21.0
   - Better Combat 2.4.0+1.21.1
4. 未安装 Combat Roll 时使用模组内置闪避；安装后优先使用 Combat Roll 的翻滚逻辑。
5. 多人游戏中，客户端与服务端必须安装相同版本的 MechanicianCombat。
6. 将 mods/MechanicianCombat-r774.jar 放入 mods 文件夹。
7. 本分发包不包含 Fabric Loader、Fabric API 或任何第三方前置 JAR。
8. 本版本没有修改任何第三方前置模组的内容。

二、基础枪械

1. 主手持有本模组枪械。
2. 按住右键瞄准，瞄准期间按左键射击。
3. F 键装填；持枪时鼠标中键也可装填。
4. 鼠标滚轮切换当前弹仓的弹药。
5. K 键打开弹药存储/弹药环界面。
6. 原版潜行键用于进入或退出专注射击。
7. 站立且非瞄准时，左键执行枢德之裁近战攻击。
8. 持枪时左键不会破坏方块。

三、枢德之裁近战

1. 快速点按左键依次使用 ATK1、ATK2、ATK4；长按会衔接 ATK3 蓄力与 ATK_hold_over。
2. ATK3 蓄力完成后长按左键进入后续攻击；超过蓄力保持点会自动释放。
3. ATK2/3/4 使用资源中的专属腿部动作，近战期间不会切换到行走或奔跑腿部动画。
4. ATK_hold_over 结束后播放 ATK_holdover_to_idle 专用收势。
5. 近战动作中段最低移动输入为正常速度的 30%，命中时按攻击类型触发 hitstop。
6. 加速并前进时左键可触发冲刺攻击；冲刺结束和硬直结束后可继续翻滚或恢复移动。
7. 近战命中实体时播放击中音效、屏幕震动和斩击粒子。

四、战斗背包

1. 背包装备在 Accessories 的 back 槽；X 键使用已安装的背包技能。
2. 背包核心和便携发射器需要在背包改装台中安装。
3. 组装后的核心、发射器和零件可再次放入改装台取回，离开界面后零件保存在背包中。
4. 便携发射器会使用副手槽保存可发射物；副手非发射物不能直接放置。
5. 支持烟花、箭、药水箭、风弹和三叉戟等便携发射物。
6. 跳跃推进器、导弹舱、自动发射器、召唤天线和战旗需要对应零件。

五、战旗

1. 在背包炮台槽安装战旗后，满足地面、状态和冷却条件时按 X 施法。
2. 非持枪状态与持枪站立状态均可使用；具体可用性由当前状态机判断。
3. 施法过程中战旗会按资源动画展开并在动画定位器位置生成旗帜实体。
4. 旗帜会为周围友方提供增益，持续时间结束后进入冷却。
5. 战旗施法音效按第 1、3、17、18 tick 播放；若仍无声音，请检查 latest.log 中的
   “War Banner cast sound” 与“声音资源自检”记录。

六、固定狩猎炮台

1. 手持机械师猎矛时右键地面部署固定狩猎炮台。
2. 炮台播放召唤动画后进入待机，自动索敌并使用 muzzle1/2 发射熔铁弩矢。
3. 炮台累计发射 8 枚后消失，猎矛以忠诚形式返回；空手右键炮台可提前回收。
4. 最多同时部署 3 个炮台。

七、机械师盔甲

1. 底衣装备在 Accessories 饰品栏；必须先装备底衣才能穿戴胸甲、腿甲和战靴。
2. 头盔在完整装备后显示，G 键切换展开/收起。
3. 胸甲改装台可安装肩盾、守护图腾和灵魂锁链等零件。
4. 肩盾提供自动格挡充能；守护图腾提供类似不死图腾的触发效果。
5. 灵魂锁链在攻击实体时按概率连接附近目标并传递不同比例伤害。

八、故障排查

1. 启动后查看 latest.log 中以下内容：
   - “声音资源自检”应显示全部资源 OggS 文件头有效。
   - “War Banner cast sound”应在战旗施法时出现。
   - “melee impact”应记录近战命中冻结参数。
2. 如果动画或模型缺失，确认使用的是 r774 且未同时放置多个 MechanicianCombat JAR。
3. 本分发包不附带运行日志。
