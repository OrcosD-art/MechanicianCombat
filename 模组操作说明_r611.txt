MechanicianCombat r611 操作说明
Minecraft：1.21.1
Mod 名称：MechanicianCombat
内部 ID：tkgun

一、安装要求

1. 使用 Minecraft 1.21.1 与 Java 21。
2. 需要 Fabric Loader 与 Fabric API。
3. 必需内容前置：GeckoLib、Player Animator、Accessories、owo-lib。
4. 推荐版本：
   - Fabric Loader 0.18.2
   - Fabric API 0.116.17+1.21.1
   - GeckoLib 4.8.2
   - Player Animator 2.0.4+1.21.1
   - Accessories 1.1.0-beta.54+1.21.1
   - owo-lib 0.13.0-alpha.15+1.21
5. Combat Roll 2.0.6+1.21.1 与 Shoulder Surfing Reloaded 4.21.0 为推荐兼容前置；未安装 Combat Roll 时使用模组内置闪避。
6. 多人游戏中，服务端和所有客户端必须安装相同版本的 MechanicianCombat。

二、基础枪械操作

1. 主手持有本模组枪械。
2. 按住右键瞄准，瞄准期间左键射击。
3. F 键装填；持枪时鼠标中键也可装填。
4. K 键打开独立弹药环。
5. 持枪时滚动鼠标滚轮切换当前枪械弹仓中的弹药。
6. 原版潜行键用于进入或退出专注射击状态。
7. 站立持枪且非瞄准时，左键执行武器近战或技能相关动作。
8. 持枪时左键不会破坏方块。

三、弹药与状态

1. 枪械弹仓独立保存；腰射装填消耗 6 颗对应弹药。
2. 专注射击从独立弹仓逐发消耗弹药。
3. 蹲射热量达到上限或弹匣最后一发耗尽后进入过热。
4. 弹种伤害与效果显示在物品详情栏。
5. 不同弹种拥有爆炸、穿透、追踪、范围伤害、音爆或散射等独立效果。

四、机械师盔甲

1. 底衣装备在 Accessories 的 cape 饰品槽；胸甲、腿甲和战靴使用原版装备槽。
2. 必须先装备底衣，才能正常穿戴另外三件。
3. 底衣被移除时，外层三件会自动卸下并返回物品栏。
4. 穿戴底衣后，原版玩家头部以下身体由底衣模型替代。
5. 第一人称手部使用底衣贴图。
6. 胸甲 F1/F2 前摆与后摆会随移动和转身摆动。

五、闪避、翻滚与滑铲

1. 未安装 Combat Roll 时，默认左 Alt 使用内置闪避键；安装后使用 Combat Roll 当前绑定的翻滚键。
2. 持枪时可按现有状态机执行翻滚、滑铲和翻滚后快速专注。
3. 同时穿戴底衣、胸甲、腿甲、战靴，并装备安装过核心的战斗背包时，非持枪状态也可闪避。
4. 每次闪避开始会获得短时间加速；连锁闪避触发后进入冷却。
5. 翻滚、滑铲及冷却期间仍受服务端状态机限制，重复输入不会跳过动画或冷却。

六、战斗背包

1. 战斗背包装备到 Accessories 的 back 槽。
2. X 键为背包功能键。
3. 背包核心与便携发射器需要在背包改装台中安装。
4. 便携发射器可使用副手槽作为发射物存储空间。
5. 自动便携发射器会扫描可见目标、消耗充能并切换目标。
6. 召唤天线可标记目标并召唤铸造傀儡。
7. 背包核心是完整盔甲提供非持枪闪避的必要条件。
